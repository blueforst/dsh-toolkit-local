# 安装与配置

从 [GitHub Actions](https://github.com/blueforst/dsh-toolkit-local/actions) 下载成功构建的 `dsh-toolkit-local-0.1.3` 并解压。macOS 官方桌面版先完全退出应用，在解压目录执行：

```sh
"/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh" plugin --profile desktop add --ignore-scripts --save-exact ./forst-dsh-toolkit-local-0.1.3.tgz
```

Web 版需要 Node.js 24.9 或更高版本：

```sh
dsh plugin --profile web add --ignore-scripts --save-exact ./forst-dsh-toolkit-local-0.1.3.tgz
```

安装后重启 DSH。三个组件可在工具包详情页分别启用。升级时用新安装包重复安装命令。

## 网页搜索

打开「插件 → 网页搜索」，选择 DeepSeek Messages、DeepSeek Search API 或 Tavily。选择 Tavily 时，在同一页输入 [Tavily API Key](https://app.tavily.com/) 并保存。DSH 已有 `TAVILY_API_KEY` 时可直接保存供应商选择。密钥通过 DSH 凭据服务保存。

Tavily 使用官方 Search API 和 basic 模式。网页抓取由同页的「网页抓取」独立设置。关闭网页搜索组件或卸载工具包前，请先将默认搜索切回 DeepSeek。

## 额度与费用

额度监控读取 DSH 凭据服务中的 `OPENCODE_GO_API_KEY`，可复用模型设置中保存的密钥或同名环境变量。侧栏展开并可见时每分钟刷新。

会话费用根据 DSH 所用的 Pi 模型目录估算。详见[费用说明](费用说明.md)。

## 卸载

先退出桌面版或停止 Web 进程，用安装时对应的 CLI 和 profile 执行 `plugin --profile <desktop|web> remove @forst/dsh-toolkit-local`。同一个 profile 安装一个工具包即可，服务器版已经包含额度与费用功能。

## 开发

```sh
npm ci --ignore-scripts
npm run check
npm test
npm pack
```

SDK 合约测试使用 `DSH_ENTRYPOINT` 指向已安装 DSH 的 `lib/bin.js`，运行 `node --test tests/*.integration.mjs`。历史基线见[验收记录](验收记录.md)。
