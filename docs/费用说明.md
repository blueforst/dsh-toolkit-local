# Pi 会话费用口径

插件直接从当前 DSH CLI 入口和 `@deepseek-ai/dsh-llm-pi-ai` 适配器依赖定位 `@earendil-works/pi-ai`，使用其模型目录及 `calculateCost()`。不会复制或硬编码价格表。

DSH 当前适配器会保留 token 用量，但未持久保存 Pi 的 `usage.cost`。因此插件根据完整历史事件重新计算：输入、输出、缓存读、缓存写分别使用 Pi 返回的对应金额，总计使用 `total`。推理 token 不重复相加。

同一轮同一步的重复结算替换旧值；明确开始重试后累计新的尝试；有用量记录的压缩摘要计入金额。未知模型或缺失用量标记未计价，金额旁显示星号。

浮窗始终展示输入、输出、缓存读；只有当前会话累计的缓存写费用大于零才展示缓存写。DeepSeek 自动建立缓存，但没有独立缓存写收费项；Claude 等模型可以有独立缓存写费用。

刷新、切换会话、分页不会丢失完整日志的累计值。Pi 版本变化或投影结构升级后，会使旧缓存失效并重新回算。历史金额因此可能随当前目录价格变化。

Pi 目录估算与供应商账单、Go 月额度是不同口径。官方月额度条读取 Go 的 usage API；不以估算金额推导更精细的额度百分比。

参考：[DeepSeek 定价](https://api-docs.deepseek.com/quick_start/pricing/)、[Claude 提示词缓存](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)、[OpenCode Go](https://opencode.ai/v2/docs/console/go/)。
